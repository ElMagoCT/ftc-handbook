Contributing to this handbook

How it is built

  • Plain HTML, CSS, and JavaScript. No build step, no framework. Open any page in a text editor and change it.
  • One page per topic in the repo root. Shared styles in assets/css/style.css, behavior in assets/js/app.js, interactive diagrams in assets/js/sims.js.
  • Glossary terms live in assets/js/glossary.js. Add a word there and it becomes clickable everywhere automatically.
  • Missions are the .mission cards on each page. The Missions page collects them on its own.
  • Hosted from the GitHub repo. Pushes to main publish the site.

How to add something

  1. Get access. Ask a lead for an invite to the repo.
  2. Make a branch named for the change (add-turret-notes).
  3. Edit the page. Copy an existing card or dropdown and change the text. Keep it short: bullets, numbers, no paragraphs.
  4. Check it locally by opening the file in a browser, or run python3 -m http.server in the folder so search works.
  5. Open a pull request. A lead reviews and merges. The live site updates on its own.
Snippets to copy templates

A card:

<div class="card">
  <span class="eyebrow">Label</span>
  <h4>Title</h4>
  <p class="small">One or two sentences.</p>
</div>

A dropdown:

<details class="more">
  <summary>Short title <span class="hint">detail</span></summary>
  <div class="body">
    <ul><li>The long version.</li></ul>
  </div>
</details>

A callout (tip, warn, rule, story, bad):

<div class="callout tip"><span class="ico">Tip</span><div><p>Text.</p></div></div>

A mission:

<div class="mission">
  <div class="head"><span class="eyebrow">Mission X1</span><span class="lvl"><i class="on"></i><i></i><i></i></span></div>
  <h3>Title</h3>
  <ul><li>Step.</li></ul>
  <div class="done"><strong>Done when</strong> a measurable result.</div>
</div>

A glossary term (in glossary.js):

"capstan": { term: "capstan drive", aliases: ["capstan"], def: "One or two plain sentences.", see: ["backlash"], link: "design.html#gearing" },
  • An interactive diagram: <figure class="sim" data-sim="gear-ratio"></figure>.
  • Available: gear-ratio, gear-train, mecanum, path-compare, fourbar, slides, pid, motor-picker, arm-torque, servo-power, tolerance, sizing-cube, intake, cycle-calc, odometry, center-distance, field-centric, current-budget.
Style
  • Write like you are explaining it to a teammate.
  • Specific numbers, real part names, short sentences.
  • No paragraphs longer than three lines.
  • If a rule number is involved, cite it and say which season's manual.
  • Photos need a caption and, if they are not ours, a source.
