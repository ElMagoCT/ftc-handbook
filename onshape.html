Onshape

Every tool you will actually use, and the judgment call behind each one.

Onshape is browser-based, free for students, and built for teams editing the same robot at once.

Setup and the interface

Getting an account

  1. Sign up at onshape.com/education with a school email. The education plan is free and has the full toolset (branches, sheet metal, FeatureScript).
  2. Make a team folder. One shared folder per season, owned by a mentor or a student who will not graduate mid-year. Everyone else gets "Can edit."
  3. Set units before anything else. Document properties → default units → millimeters if you build on goBILDA or REV. A bare number typed later gets the default unit, and derived parts from other documents fall back to it.

A document is the shareable, versioned container. Tabs are views inside it.

Navigation, views, and selection detail

Mouse

  • Right-drag to orbit, middle-drag to pan, scroll to zoom.
  • Click a view cube face to snap. Right-click a face or plane → View normal to, or press N.
  • Shift + view cube arrows rotates 90° steps.

Show / hide

  • Planes, axes, origin, mate connectors, and sketches each have their own toggle in the view menu.
  • Hide sketches you are done with. A busy screen makes you click the wrong edge.
  • Section view lets you look inside an assembly without hiding anything.

Selection filters

  • Filter to faces, edges, vertices, or bodies when the geometry is crowded. Faster than any shortcut.
  • Hover to wake an entity before clicking; the highlight tells you what you are about to select.

Saving

  • There is no Save. Every edit is stored instantly.
  • What you save on purpose is a Version: a named, permanent snapshot. Make one before every event and every big change.
Sharing and permissions detail
  • Can view for builders and mentors who only need to look. Can edit for designers. Full access only for the owner and one backup.
  • Share the folder, not each document, so new documents inherit permissions.
  • Follow a collaborator's view from the people icon to watch what they are doing live. Pin comments to geometry instead of texting screenshots.
  • Link sharing is fine for judges and sponsors: view-only, no account needed.

Sketching

Where beginners actually fail. A sketch is a feature like any other: 2D entities on a plane, and a closed loop is a region that features consume.

L

Line / polyline

Chain clicks, Esc to end. Click-drag off an endpoint for a tangent arc.

R

Rectangle

Center-point rectangle on the origin for anything symmetric: two dimensions lock it, and it grows both ways when a dimension changes.

C

Circle

Center-point or 3-point. Pick based on which dimension you actually know.

Q

Construction toggle

  • Construction geometry still constrains and dimensions.
  • It never forms a region.
  • Centerlines are for revolve axes and diameter dimensions.
D

Dimension

  • Smart dimension auto-detects length, angle, radius, diameter.
  • Type a variable name (#wall) instead of a number when it might change.
Tool

Slot

Straight or arc. Beats two lines and two arcs every time because it stays a slot when you resize it.

Tool

Polygon

  • Inscribed vs circumscribed.
  • Hex shaft holes are circumscribed on the across-flats size (5 mm for FTC hex, 8 mm for goBILDA REX).
Tool

Spline

  • Interpolate passes through points; control-point pulls the curve.
  • Minimize points.
  • A bad spline becomes a bad loft.
Tool

Use / Project

  • Pull an existing 3D edge into the sketch as a live-linked reference.
  • Great for matching a hole pattern, dangerous if the edge gets deleted later.

Constraints and degrees of freedom

Read the colors

  • Blue: under-constrained. Something can still move.
  • Black: fully defined. Zero degrees of freedom. The target for every sketch.
  • Red: over-constrained or conflicting. Remove one constraint, not both. The classic conflict is parallel plus an equal-angle dimension.
  • Gray: construction or fixed. Orange: driven or redundant.

The DOF counter in the bottom bar shows how many numbers Onshape still needs. Drag something: whatever moves is exactly what is still free.

The working set

  • Coincident (points), concentric (centers), equal, parallel, perpendicular, tangent, horizontal, vertical, midpoint, symmetric (three selections: two entities and the mirror line).
  • Pierce locks a sketch point to where a 3D edge crosses the plane. The sweep constraint.
  • Fix zeroes DOF without saying why. It hides the problem; it does not solve it. Avoid.
  • Constraints state relationships. Dimensions state numbers. Use a constraint whenever one will do.
Three habits that fix most red sketches detail
  1. Anchor first. Constrain one point to the origin before anything else. The origin is the one thing that cannot move.
  2. One constraint at a time, watching the counter. If it jumps the wrong way, undo.
  3. Hold Shift while drawing to suppress inferred constraints when Onshape keeps snapping to things you do not want. Inferred constraints are real and count against your DOF; they are the source of most red sketches.
  • The constraint manager lists every constraint as a row.
  • Select a row and the geometry highlights.
  • Delete from there instead of hunting glyphs.
Editing and multiplying geometry detail

Trim, extend, split

  • Trim is the most-used sketch tool after line.
  • Trim early to keep sketches clean.
  • Existing constraints on trimmed segments can vanish; recheck the counter.

Offset

  • Chain an outline and offset it for wall thickness in the sketch when the wall is part of the profile's identity (a slot end, a laser relief).
  • Shell later when it is a finishing operation.

Mirror and sketch patterns

  • Mirror across a construction line creates symmetric constraints.
  • Linear and circular sketch patterns take a count you can drive with a variable.
  • Pattern the sketch for holes and cuts (fast rebuild).
  • Pattern the feature for complex shapes.

Images

  • Insert a photo onto a plane, scale it to one known dimension, sketch over it.
  • Traced splines are never truly parametric; snap to round numbers where you can.
  • One sketch, one purpose. A 5-entity sketch beats a 30-entity sketch.
  • A master sketch that holds the critical dimensions, with everything else referencing it, is the professional pattern.

Creating geometry

Extrude

  • New / Add / Remove / Intersect.
  • Blind or Symmetric nine times out of ten.
  • Through-all and Up-to-face are situational.

Revolve

  • Profile plus axis (edge, sketch line, or centerline).
  • Correct for anything rotationally symmetric.
  • Extruding a circle is not the same thing.

Sweep

One profile along one path. Use pierce to attach the profile. Constant cross-section only.

Loft

  • Two or more profiles.
  • Vertex matching and profile order decide smooth versus twisted.
  • Every cross-section stays editable.
Rule
  • Extrude for prismatic geometry.
  • Revolve for rotational symmetry.
  • Sweep for a constant cross-section along a path.
  • Loft for controlled transitions.
  • Before you commit, ask: if this dimension changes, how many features break? The answer should be zero.

Modifying geometry

Fillet

  • Fillets go last. They replace an edge with a face, and anything downstream pointing at that edge dangles.
  • Tangent propagation on by default.

Chamfer

  • Equal distance, two-distance, or angle-distance.
  • The manufacturing-correct choice for a lead-in or a deburr on machined parts.

Shell

  • Deletes the faces you pick, offsets every remaining face inward.
  • Shell before fillets, or the fillets round the inside too and it fails.

Hole

  • Beats extrude-remove for any real hole: standards, clearance and tapped sizes, and drawing callouts for free.
  • Size to real hardware (M3, M4), not round numbers.

Draft

Tilt faces relative to a neutral plane. 1–3° for molding; also a trick to reduce FDM overhangs.

Rib

Stiffener from a sketch line. Adds bending stiffness for little mass on printed brackets.

Linear / circular pattern

  • Feature, face, body, or part mode.
  • Count and spacing, or count and distance.
  • Skip instances.
  • Never pattern a fillet: pattern the base feature, fillet once at the end.

Mirror

Features or bodies across a plane, merged or separate. Left and right drivetrain plates in one operation.

Move / delete / replace face, Transform

  • Direct editing.
  • Right for imported dumb solids and throwaway tweaks.
  • A regret on any part that needs to stay parametric.
Order of operations, and why half of all failures are this detail
  • The feature tree is a recipe. Onshape re-runs it top to bottom every time anything changes.
  • Shell needs the faces that exist at that point in the tree. Fillet after shell, not before.
  • Holes and patterns before fillets. Fillets last, chamfers with them.
  • Drag the rollback bar above a failed feature to see the model as it was, then step forward. It is the best debugging tool in the program.
  • Suppress a feature to test whether it is the culprit before you delete it.
  • Rename every feature as you make it. "Extrude 14" tells nobody anything in March.

Structuring a model

The module that separates a hobby model from a robot CAD a team can actually work in.

Reference geometry and mate connectors

  • Planes: offset, at an angle, mid-plane, through three points. Name them ("Arm Pivot Plane").
  • Sketch on origin planes and named planes, not on faces. A sketch on an origin plane cannot dangle. A sketch on a face dies when the face does.
  • Define mate connectors in the Part Studio, not in the assembly. Explicit beats implicit. Put one at every motor shaft, bearing bore, and pivot, named like motor_output_shaft or pivot_center.
  • This single habit makes assembly roughly ten times faster.

Multi-body and Booleans

  • Several bodies in one Part Studio is normal here, even if your last CAD program discouraged it. Related parts (both drive plates, a bracket and its cover) belong together.
  • Boolean: union, subtract, intersect, with "keep tools" when you still need the tool body.
  • The cast-housing pattern: model the outside and the cavity as separate bodies, then subtract. Each changes independently.
  • Split by plane, surface, or sketch to cut one body into modular parts.

Derive and the skeleton model

  • Derive brings geometry from another Part Studio as a live link.
  • The skeleton pattern: one Part Studio holds every critical interface dimension (wheelbase, motor positions, slide mount). Every subsystem derives from it. Change the chassis width once and the drivetrain, arm, and slide Part Studios all follow.
  • Derive beats in-context for anything worked on by more than one person.

Variables and configurations

  • Variables for continuous or shared numbers: #wall = 3 mm, #clearance, #plate_thickness. Put them in a Variable Studio tab so every Part Studio and Assembly shares them; it doubles as a readable spec sheet.
  • Configurations for discrete named states: a channel in three lengths, a bracket with or without a hole, an arm in "stowed / scoring" positions. Checkbox, list, and variable inputs.
  • Do not use both for the same thing. The power combo: variables define the parameters, configurations select preset sets of them.
Configuration

Variable inputs: custom sizes within limits.

Configuration

Checkbox: turn a feature on or off.

Configuration

List: named positions or set sizes.

Materials, mass properties, and designing for weight detail
  • Material is physical, appearance is visual, and they are independent. Assign a material to every part or the mass and the BOM lie to you.
  • Mass properties gives mass, volume, center of mass, and inertia. Export the BOM to a spreadsheet and sum by subsystem to find where the weight is.
  • Structural intuition: triangles do not deform under load, rectangles do. Doubling wall thickness gives about four times the bending stiffness at twice the mass. Material off the load path is dead weight.
  • Track center of mass as the robot grows. A high, off-center CG is why robots tip when they strafe.

Assemblies

Fundamentals

  • Insert from the current document, other documents, or the Standard Content library (bolts, nuts, bearings).
  • Ground exactly one part. Mate everything else to it or to something mated to it.
  • Fastened, revolute, and slider mates cover most of what you will ever build. Set limits and offsets as you go, not as cleanup.
  • Drag-test after every mate. If it moves in a way the real part cannot, fix it now.
  • Onshape has no collision detection. Mate limits are how you stop an arm swinging through the frame.

Relations, sub-assemblies, patterns, and Replicate detail

Relation mates

  • Gear (ratio), rack and pinion, screw (pitch), linear.
  • Simulate a two-stage reduction or a slide's string ratio before anything gets machined.
  • They need existing revolute or slider mates first.

Sub-assemblies

  • One per subsystem (drive module, intake, lift).
  • Rigid vs flexible decides whether the mechanism still moves after you nest it.
  • Edit in context from the top level.

Assembly patterns

Linear, circular, or by mate connector. Four wheel modules from one. Mirror for left and right.

Replicate

Places a fastener at every matching hole in one click. This is the tool that makes screws worth modeling.

Good practice

  • Mate to explicit mate connectors, never to implicit face references. Faces get rebuilt; named connectors survive.
  • Name instances by function ("left_front_module"), group them in folders.
  • Interference detection and named positions (stowed, scoring, climbing) before you call a design done.
  • Exploded views for the builders. Every tightly packed mechanism gets one.
  • Suppress heavy sub-assemblies while working on something else; big assemblies get slow.

Collaboration and data

Versions and branches

  • Workspace is the live state. A version is a named, immutable snapshot ("v1.2 — fixed bearing bore").
  • Branch for experiments ("wide-wheel-test"). Merge back or abandon.
  • Team pattern: one branch per subsystem, merge at design-freeze milestones. Version before every event.

In-context design

  • Edit a part while seeing the assembly as a ghost. Auto-updates when neighbors move.
  • Breaks when parts get renamed or deleted, or references go circular. Rebuild times climbing past ten seconds is the symptom.
  • Limit references to what must match: bolt patterns and mating faces. Prefer skeleton plus derive when several people edit.

Import and export

  • Import STEP from vendors (goBILDA, REV publish everything). Imported geometry has no feature tree.
  • STEP for geometry, STL or 3MF for printing, DXF for laser and CNC, PDF for drawings.
  • Check units, coordinate system, and body selection before you export. Every time.
Folder structure that survives graduation detail
  • Team / 2026-27 BIOBUZZ / Robot for the competition robot, with one document per subsystem or one document with sub-assemblies (pick one convention and stick to it).
  • Team / Library for reusable parts: motor mounts, bearing blocks, the hardware-standards document everyone derives from.
  • Team / Archive for old seasons: version it, move it, keep the workspace clean.
  • Owner is a mentor or a long-tenured student. Transfer ownership before seniors leave.

Sheet metal, frames, surfacing

Essential when you need them, irrelevant when you do not.

Sheet metal

  • Sheet metal model: thickness, default bend radius, K-factor (about 0.3–0.5; it sets how much the flat pattern stretches), corner relief.
  • Base flange and edge flange do almost everything. Hem, tab, and manual bend for the rest.
  • Design in the bent state and let Onshape compute the flat. Export the flat pattern as DXF for the water jet or laser.
  • Minimum flange length about four times material thickness. Wrong relief type tears the corner.
  • FTC use: brackets, battery trays, side plates from 1.6 to 3.2 mm (1/16 to 1/8 in) aluminum. See Manufacturing.

Frame tool

  • Draw a 3D wireframe sketch, run profiles along it. The sketch stays the source of truth.
  • Profiles: square tube, round tube, angle, C-channel, or a custom profile authored from a vendor extrusion.
  • Joints: cope, miter, butt. Pick the one you will actually cut. Gussets and end caps come with it.
  • FTC use: chassis rails and arm structures from real extrusion sizes, for teams cutting their own stock.

Surfacing and direct editing

  • Surfaces have no thickness. Fill, offset, extend, and thicken exist.
  • When to use: a shape solid tools cannot make, or repairing an imported model with a broken face. That is the whole list.
  • Direct editing (move face, delete face, replace face): fine on an imported vendor STEP you need to simplify. Wrong on your own parametric parts.

Drawings

Views and sheets

  • New Drawing tab, pick a template and paper size. Third-angle projection in the US.
  • Standard, isometric, section, and detail views. Scale override per view.
  • The purpose is to tell someone who cannot open your CAD (a sponsor's machinist, a water jet operator) exactly what to make.

Annotation

  • Smart dimension in drawing context; thread callouts come from the Hole tool automatically.
  • GD&T you will actually use: position, flatness, perpendicularity. Tolerance only what matters. Over-dimensioning communicates less, not more.
  • Balloons linked to the assembly BOM, revision table, a team title block with logo and standard tolerance note.
  • Sheet metal: bent view and flat pattern on the same sheet with a bend table.
  • Export PDF for the notebook and portfolio. Judges like a real drawing.

Troubleshooting and the professional workflow

Fixing a broken model

  1. Read the error text. Red is failed, yellow is a warning. It usually names the missing reference.
  2. Roll back above the failure and step forward until it breaks. Now you know which change did it.
  3. Reassign dangling references by editing the feature and re-picking the face, edge, or plane.
  4. Open profile? Use "Show profile" in the sketch to find the gap. Zoom in on every corner.
  5. Suppress, do not delete, while you test. Reorder features if an add and a remove are in the wrong order.
  6. Know when redrawing beats debugging. A ten-feature part with three dangling references is faster to rebuild than to rescue.

Team conventions

  • Build for change, not for today. One well-designed extrude beats five hacked ones.
  • Name every feature, body, mate, sketch, variable, and tab. Keep trees under about 30 features; split into sub-assemblies past that.
  • The readability test: can a new teammate understand your feature tree in five minutes?
  • Variable Studio is the source of truth for dimensions. Versions are checkpoints; branches are experiments.
  • Workflow: version → review → comment → approve. One student owns each subsystem document.
  • A shared hardware-standards document (bearing sizes, motor bolt patterns, hex profiles) everyone derives from.
Checklists

Before sharing: features named, variables extracted, version created, BOM accurate.

Before manufacturing: material assigned, mass reviewed, tolerances called out, interference check passed, export units checked.

Before competition: version tagged with the event name, branches merged, archive copy made.

  • The final test: if the motor bore diameter changes, how many features break?
  • The answer should be zero.
FeatureScript and community features detail
  • Every Onshape feature is written in FeatureScript, and you can add custom ones from the toolbar's "+" button by pasting a document link.
  • Worth installing on day one: a spur gear generator, sprocket and timing pulley generators, a belt/chain path tool with center-distance calculator, internal and external thread features, lightening and pocketing tools, the McMaster-Carr hardware insert.
  • Find them in the Onshape App Store, the Onshape forum, and FRC team GitHub repos (teams like 2910 and 3847 publish libraries).
  • Writing your own: a 15-line feature is an annotation block, a precondition block, and an opExtrude. Usually, though, find one that exists.

Design for manufacturing

FDM 3D printing

  • 45° overhang limit without support. Bridges of 40–60 mm are fine in PLA.
  • Minimum wall at least two nozzle widths (0.8 mm on a 0.4 nozzle); three or four walls for strength.
  • Layer orientation costs 30–50% strength across layers. Orient so load runs along layers.
  • Print holes 0.2 mm undersized and drill to size, or use the tolerances in Manufacturing. Teardrop horizontal holes.
  • Heat-set insert boss: insert OD plus about 0.3 mm. Self-tapping boss core at 90% of thread major diameter.
  • Design so the next revision is one variable change.

Laser and sheet

  • Kerf 0.1–0.3 mm; offset inside cuts out and outside cuts in, or let the cutter software compensate.
  • Minimum feature about 1.5 times material thickness. Relief circles at inside corners.
  • Tab-and-slot with thickness plus 0.1 mm. Living hinges follow grain.
  • Export DXF from the flat pattern tab for sheet metal, from a sketch projection otherwise. Check for duplicate lines, open paths, wrong scale before sending.
  • Acrylic cracks at sharp re-entrant corners. Aluminum needs a fiber laser or a water jet.

CNC machining

  • Inside corner radius at least the endmill radius. Pocket depth to width no more than 4:1.
  • No undercuts without a multi-axis plan; everything reachable from one fixture on a 3-axis.
  • Standard drill sizes; tap drill callouts (M4×0.7 → 3.3 mm drill). Tapped depth 2.5× diameter in aluminum.
  • Bearing bores as press fits (H7). Counterbore depth = head height + 0.5 mm.
  • 6061 for most work, 7075 for high-stress hubs. Design to stock sizes.

Missions

Mission O1

The parametric box

  • Hollow box with a press-fit lid, every dimension from Variable Studio.
  • Change the width from 120 to 160 mm. Nothing may break.
Done when one variable change updates box, lid, and wall thickness with zero errors.
Mission O2

Fully define it

  • Take a bracket profile with 15 entities and fully define it using constraints only, no Fix.
  • Narrate the DOF counter as you go.
Done when every line is black and you can explain each constraint's job.
Mission O3

Motor mount, two ways

  • A Yellow Jacket mount plate: printed version and a sheet-metal version.
  • Shared skeleton sketch with #motor_bore and #bolt_circle.
  • Drawing with hole callouts for each.
Done when changing the bolt circle updates both parts and both drawings.
Mission O4

Drive module sub-assembly

  • One mecanum module: motor, mount, wheel, bearing block, all mated to explicit mate connectors.
  • Pattern it to four. Mirror where needed.
  • Interference check, exploded view, BOM export.
Done when the wheels spin when dragged, the BOM has real part numbers, and a builder can assemble it from the exploded view.
Mission O5

Fix the broken document

  • A mentor hands you a document with four failed features.
  • Fix all four using rollback, reassignment, and reorder. No redrawing.
Done when the tree is green and you wrote one line per failure on what caused it.
